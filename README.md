# PAP Service Logistics

PAP 服務物流組織與作業介紹網站（中文／English），版型沿用 [RMA 售後零件規劃平台](https://github.com/sandyliu3056/RMA)。

> 本網站內容屬公司內部資料，請勿對外散布；資料以原始文件為準。

## 網站架構

| 主頁 | 子頁 |
|---|---|
| 網站介紹（首頁） | 導言、PAP 至各國子公司路線圖與子公司代碼導覽、網站架構 |
| 1 服務物流基礎概念 | 1-1 物流的基本概念 · 1-2 服務物流是什麼 · 1-3 備用零件的特性 · 1-4 業務模式（OBM、OEM、ODM、EMS）· 1-5 備用零件的旅程 |
| 2 產業生態系與相關公司 | 2-1 產業生態系（互動式架構圖、供應鏈角色）· 2-2 Acer · 2-3 Highpoint 服務網路 · 2-4 仁寶 Compal · 2-5 製造合作夥伴 · 2-6 Acer 家族（泛宏碁集團、集團子公司）· 2-7 服務合作夥伴 |

| 5 服務物流實際作業 | 5-1 團隊職責與主要功能（含 PAP 採購的角色與流程）· 5-2 系統 · 5-3 SPL 定義流程 · 5-4 服務 BOM · 5-5 規劃模式 |
| 6 料號規則與代碼表 | 6-1 料號命名規則 · 6-2 解碼練習 · 6-3 代碼參考（子類別、區域、子公司、其他國家與單位、HSN 代碼） |
| 7 名詞釋義 | 7-1 名詞與縮寫（售後服務名詞、證券市場名詞、縮寫說明） |
| 8 複習題與參考資料 | 8-1 複習題與答案（18 題）· 8-2 快速參考 · 8-3 資料查證 |

- 每一章都是一頁直向排版：章名區（章號、圖示、一句說明）在上、各節按鈕列黏在頂端，各節依序往下排；按鈕列會標示目前捲到的節。手機上分頁列與節按鈕列都改為單列橫向捲動，右下角有回到頂端按鈕。
- 每章有自己的主題色（設計變數 `--ch`、`--ch-bg`、`--ch-ink`，定義於 `index.html` 的 `NAV`）：1 藍、2 藍紫、3 綠、4 珊瑚紅、5 橘、6 青綠、7 石板灰、8 紫，套用在分頁色條、章名區、節按鈕、內容區塊、表頭、流程節點與卡片。
- 內容以格子卡片呈現：`.cards`（重點卡）、`.steps`（有箭頭的流程步驟，手機改直排）、`.compare`（並排比較）；`<div class="cards" data-abs="hq,ro,ns">` 會依代碼資料庫自動產生角色卡。
- 7-1 縮寫索引為主題分類的小卡片格子（縮寫、英文全稱、中文名稱、一句說明），可即時搜尋、依主題篩選或選「全部」依主題分組列出，點卡片展開完整說明與來源。
- 右上角可切換中文／English、字型與主題（預設土色，另有綠色、藍色），設定會記在瀏覽器裡。
- 3-1 全球區域內的全球據點依「Acer Around the World」據點名錄整理，地圖可切換全球、歐洲、亞太檢視。
- 第 2 章各公司之沿革與業務資料取自公開網路資料（查詢日期 2026 年 10 月）；每條敘述的查證狀態列於 8-3 資料查證與 `VERIFICATION.md`，僅單一來源或未能證實者分別標示；與內部文件不一致時，以內部文件為準。
- 內文中所有代碼與縮寫皆可點選：說明視窗顯示一句話說明、全稱、類別、國家／地區、所屬單位、說明、來源與查證狀態（資料在 `index.html` 的 `AB` 陣列）。
- 地圖下方的國家代碼導覽（國旗＋代碼＋英文＋中文）與地圖標記互相連動。
- 2-1 產業生態系的企業架構圖預設顯示全圖，可縮放、拖曳、重設，點選節點開啟詳細資訊；資料在 `org.js`，各節點附查證狀態。
- 公司 logo：放入 `logos/<代號>.svg|png` 即自動顯示（見 `logos/README.md`）。
- 網址加上子頁代碼可直接開啟該節，例如 `#org-pap`、`#ref-terms`；改版前的代碼（如 `#ref-abbr`、`#org-offices`）會自動對應到新位置。

## 檔案

- `index.html`：網站本體（HTML、CSS、JavaScript；代碼資料庫 `AB`）
- `org.js`：企業架構圖的節點、連線與版面資料
- `verify.js`、`VERIFICATION.md`：資料查證清單（同一份資料，分別供網頁與閱讀用），由 `python3 tools/build_verify.py` 依 `src/data/ver_data.json` 與 `src/data/ver_sources.json` 產生
- `world.js`：世界地圖輪廓
- `vendor/rough.js`：手繪線條（[rough.js](https://github.com/rough-stuff/rough) 4.6.6，MIT，授權見 `vendor/rough-LICENSE.txt`），用於架構圖與各流程圖的方框、連線與箭頭
- `flags/`：國旗圖示；`logos/`：公司 logo
- `favicon.svg`

純靜態網頁，不需要建置。在 GitHub 的 Settings → Pages 選 `main` 分支、根目錄即可發布。
